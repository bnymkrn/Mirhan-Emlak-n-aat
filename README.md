Mirhan Emlak & İnşaat - Gayrimenkul Portalı
Mirhan Emlak & İnşaat, Kocaeli bölgesinde lüks konut ve yatırım danışmanlığı sunan profesyonel bir gayrimenkul platformudur. Bu proje, gayrimenkul ilanlarının sergilenmesi, yönetimi ve kullanıcı etkileşimi için Full-Stack bir çözüm olarak geliştirilmiştir.

🌐 Canlı Yayın
Projeyi buradan inceleyebilirsiniz: www.mirhanemlakinsaat.com.tr

🛠 Kullanılan Teknolojiler
Frontend:

HTML5, CSS3, JavaScript (ES6+)

Modern Tasarım: Urbanist & Poppins tipografisi ile responsive (mobil uyumlu) yapı.

Animasyonlar: Intersection Observer API kullanılarak kullanıcı deneyimini artıran modern geçişler.

Backend & Veritabanı:

Firebase: Tamamen Firebase üzerinde kurgulanmış serverless mimari.

Authentication: Firebase Auth ile güvenli yönetici girişi.

Realtime Database: İlanların anlık olarak yönetildiği CMS altyapısı.

Optimizasyon:

Canvas API: Kullanıcıların yüklediği yüksek boyutlu görselleri tarayıcı tarafında (client-side) asenkron olarak sıkıştıran ve boyutlandıran özel bir algoritma ile sayfa hızı ve veritabanı performansı optimize edilmiştir.

🚀 Öne Çıkan Özellikler
Dinamik Yönetici Paneli (CMS): Firebase Realtime DB ile entegre, yetkilendirilmiş kullanıcılar için ilan ekleme, düzenleme ve silme paneli.

Hızlı ve Akıcı Arayüz: Intersection Observer kullanımı ile görsel odaklı, akıcı bir kullanıcı deneyimi.

Performans Odaklı Görsel İşleme: İlan fotoğrafları için geliştirilen Canvas API çözümü ile web sitesinin yüklenme süresi minimuma indirilmiştir.

Mülk Sat Formu: Kullanıcıların mülk bilgilerini iletebileceği, KVKK uyumlu veri toplama akışı.
